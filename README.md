# 糖心志者

糖心志者是一个 Chrome Manifest V3 浏览器插件，用于账号池管理、播放状态展示、视频下载、版本更新和缓存清理。

## 项目介绍

当前界面不是手写相似样式，而是直接把 Figma Make「生成糖果风页面」的 React 页面源码接入插件工程：源码放在 `ui-src/`，通过 Vite 打包为 `dist-ui/txzz-ui.js` 和 `dist-ui/txzz-ui.css`，再由 `manifest.json` 作为内容脚本加载。`content.js` 只保留账号池、播放详情、下载和更新等业务能力，并通过事件状态桥把真实流程交给 React 界面展示；旧 DOM 面板、旧流程浮层和旧更新弹窗已经删除。

插件默认只显示左上角流程标签和右下角「志」字糖果悬浮球，不再用整屏背景遮挡网站内容。点击悬浮球后展开粉紫糖果风控制台，打开面板时会显示模糊蒙版，桌面端使用左侧导航和右侧工作区，移动端使用全屏面板和底部导航，把账号池、播放状态、下载任务、版本更新和缓存清理集中管理。

## 环境要求

- 操作系统：Windows 10 或 Windows 11
- 浏览器：Chrome `120.0` 及以上，或 Edge `120.0` 及以上
- 插件规范：Chrome Manifest V3
- 本地检查工具：Node.js `22.16.0` 及以上
- 本机验证版本：Node.js `25.8.0`，npm `11.11.0`
- 前端界面：React `18.3.1`，React DOM `18.3.1`，lucide-react `0.487.0`
- 播放器内核：ArtPlayer `5.4.0`（当前唯一主链路，负责完整播放器界面和交互）
- HLS 播放内核：hls.js `1.6.16`（负责 HLS/m3u8 解析和播放）
- 旧实验播放器：v3.0.0 起已清理 XGPlayer / xgplayer-hls 实验链路，当前构建只保留 ArtPlayer + hls.js，减少依赖冲突和构建风险
- 构建工具：Vite `8.0.16`，@vitejs/plugin-react `6.0.2`，Tailwind CSS `4.1.12`，@tailwindcss/vite `4.3.1`
- 依赖自检：`scripts/check-deps.mjs` 会在构建前检查 Vite、hls.js、ArtPlayer 的关键入口文件
- 远程服务：Cloudflare Worker
- 云端数据库：Supabase
- 部署工具：Wrangler `4.98.0`
- 视频转封装：`mux.js@7.0.0`
- 文件编码：UTF-8

## 核心功能

- 悬浮球入口：默认只显示「志」字悬浮球和左上角流程标签，支持桌面端和移动端拖动，不遮挡网站主体内容。
- 糖果风控制台：根据 Figma Make 设计稿重做粉紫渐变、白色卡片、圆润按钮、轻量阴影和糖果悬浮球，并补充 Shadow DOM 圆角变量兜底，避免按钮和色块变直角。
- 新界面强制接管：旧 DOM 面板、旧流程标签和旧更新弹窗已删除，浏览器页面上唯一可见入口为 Figma Make React 糖果风界面。
- 五页控制台：导航精简为总览、账号池、播放、下载、设置，去除普通用户不需要的调试入口。
- 总览页面：集中显示当前展示状态、账号池数量、播放记录数量、下载任务和最近流程。
- 页面状态展示：集中展示会员状态、扩展运行状态、账号池状态和最近流程。
- 播放状态展示：展示最近视频、播放资源体检、完整播放器、推荐线路、主备线路、分片统计、当前视频下载任务和下载入口；已查阅 hls.js、Video.js、Shaka Player、dash.js、ArtPlayer 等热门开源播放方案，当前升级为 ArtPlayer `5.4.0` + hls.js `1.6.16` 组合，补齐进度点击跳转、快进快退、倍速、热键、截图、画中画、网页全屏、断点续播、移动端手势、长按快进、双击左右快进快退、系统媒体键、HLS 清晰度切换和右键菜单；画面内控制层播放时会自动隐藏，单击视频画面会显示悬浮 UI，再次单击会隐藏顶部状态条和底部控制面板，鼠标移动和触摸只延长已显示控制层的停留时间，不会打断用户主动隐藏状态，「菜单」按线路、显示、声音、工具四组收纳，默认少遮挡视频，需要时再展开线路切换、清晰度、倍速、比例、填充、快进步长、音量、亮度、静音、截图、下载、复制等功能；页面获取到视频链接后会额外显示悬浮视频按钮，点击后暂停网页原生视频并优先请求播放器壳层进入浏览器全屏，宿主全屏兜底时会隐藏插件面板外壳、侧栏、标题栏、底部导航和其它播放页卡片，播放器外层会无框覆盖整个视口；横屏视频进入全屏时优先请求浏览器系统横屏，不再旋转整套播放器控件，因此暂停、快退、快进、菜单和退出按钮会保持正常横向排布；手机横屏小高度全屏会启用紧凑控制层，减少进度条、按钮和底部面板遮挡，视频层改为按播放器容器自身和实时可见视口尺寸贴合显示，默认原比例完整显示，并会结合 Android 横屏系统保留区、安全区和 visualViewport 偏移自动微调视频内容位置，避免裁剪、强行拉伸、插件导航栏、网页导航栏、右上角圆角、内层视频框残留或左右黑边偏移；全屏时控制层改为贴底渐变沉浸样式，进度手柄常显且进度条加粗，音量/亮度/快进快退会显示手势 HUD，并支持控制层锁屏防误触；全屏顶部提供返回退出按钮，Esc 在锁屏时先解锁、再按一次才退出全屏，键盘 L 可切换锁屏；顶部会短时显示全屏来源、视口覆盖率和容器贴合体检，诊断报告同步记录容器尺寸、当前视口、覆盖率、手机视觉居中状态和异常原因，全屏观看时鼠标会随控制层自动隐藏；推荐线路、主备线路和播放记录都支持用补全域名后的完整链接复制或打开，方便排查播放卡顿，不再暴露原始接口堆栈。
- 账号池管理：账号池页重构为控制台布局，支持本地账号、云端自动轮换和云端优先本地兜底。
- 云端轮换策略：云端账号按金币数量升序排序；获取播放详情失败或金币视频处理失败时自动切换下一个云端账号。
- 金币视频策略：先轮询所有云端账号是否已购买；如果全部未购买，则从金币数量最少的账号组中随机选择一个账号购买，失败后继续按同规则轮换。
- 云端账号卡片：统一展示账号昵称、可用状态、不可用原因、普通 VIP、尤物圈和金币余额；云端账号不提供手动选择按钮，只参与自动轮换；失效云端账号默认隐藏，可手动查看。
- 云端分类识别：前端账号池页面和后台统一识别 `cloudReadonly`、`isCloud`、`remoteId`、`cloudId`、`source=remote`、`source=qrcode` 等云端摘要标记，避免云端账号误显示到本地账号分类。
- 账号可用判定：账号池会区分账号凭据错误和视频资源异常，视频下架、播放详情缺少链接或临时接口异常不会把有成功检查记录的云端账号误判为失效。
- 关键流程提示：插件运行时会在页面左上角显示轻量流程标签，只展示同步账号池、云端账号轮换、当前使用账号、金币解锁、获取播放状态、下载合并、保存到设备和异常等关键状态。
- 添加账号面板：通过「添加账号」按钮展开，支持账号密码、账号凭证、token/deviceId 三种本地保存方式。
- 远程同步：通过 Cloudflare Worker 读取 Supabase 账号池，只在插件侧展示脱敏摘要。
- 云端服务体检：设置页可检测 `/v1/diagnostics`、`/v1/status` 和 `/v1/health`，展示密钥、数据库、账号池、异常账号和待验证账号等分项结果，并给出下一步处理建议；再次打开设置页会自动展示上次体检结果。
- 体检快捷处理：体检结果下方提供「处理账号池」「同步账号」「复制报告」三个快捷操作，可直接跳转账号池、打开失效账号视图或复制完整体检报告。
- 播放页面：通过 Worker 获取播放详情，并在面板中展示播放就绪摘要、播放资源体检分、完整播放器、推荐线路、风险提示、主线路、备用线路、刷新播放资源、复制完整链接、复制体检报告、当前视频下载任务和下载入口；完整播放器使用 ArtPlayer `5.4.0` 承担播放内核，使用 hls.js `1.6.16` 处理 HLS/m3u8，控制层由 `PlayerChrome` 模块化组件承载；主控栏左右分区，左侧播放/快退/快进，右侧音量快开、倍速快开、菜单、锁定、全屏；下方快捷条提供清晰度、填充、步长和备用线路；二级菜单按线路、画面、声音、工具分组，倍速/步长/清晰度支持芯片一键点选；支持进度拖动跳转、热键、截图、画中画、网页全屏、断点续播、移动端竖滑音量/亮度、横向滑动快进快退、长按倍速、双击三区手势、系统媒体键和锁屏防误触；页面悬浮视频按钮可一键暂停网页原生视频并进入插件全屏播放；横屏视频优先请求系统横屏，手机横屏小高度启用紧凑控制层，视频按原比例居中并自动校准安全区；当前视频下载卡片和播放记录能力保持不变，复制链接始终写入完整域名地址。
- 下载管理：接管视频详情页下载按钮，创建后台下载任务；下载页支持全部、进行中、可保存和失败筛选，也可按标题、视频编号、任务编号、阶段、失败原因或链接搜索任务，并支持按最近更新、失败优先、进度最高和文件大小排序；失败原因会按当前可见任务聚合展示，可一键复制失败摘要；失败任务可直接重试，失败筛选下可批量重试，可一键保存当前筛选和搜索结果里的全部可保存任务，也可一键复制当前结果里的完整下载源链接和任务报告；任务报告包含状态、进度、格式、大小、失败原因和完整源链接，任务卡片会显示完整源链接摘要，复制下载链接时写入包含 `https://域名/...` 的完整下载源链接。
- MP4 输出：M3U8 分片下载完成后优先转封装为真实 MP4，失败时保留 TS 兜底。
- 数据清理：支持一键清除旧版本缓存、账号池缓存、播放缓存、下载缓存、更新缓存和页面运行缓存。
- 旧数据整理：当前版本重构升级系统后不再保留旧运行数据，覆盖安装时会清空旧账号、旧播放记录、旧下载任务和旧更新状态，请重新同步云端账号池。
- 更新管理：升级为 v3 清单检测链路，实时读取远程仓库 `update.json`，对比版本号和构建号，并用 README 更新日志兜底识别清单漏更；旧更新缓存不再沿用；自动检测到新版本时会直接弹出更新弹窗，展示版本号、构建号、发布时间、检测来源和更新内容，不再只引导到设置页；设置页会展示本地版本、远程版本、检测来源、检测模式、清单地址、检测时间、下载地址、候选下载地址、实际尝试地址、缓存策略、下载策略和失败原因；点击「检查更新」会等待本次远程检测结果返回后再弹窗，避免显示旧结果；已经检测到远程信息后，下载按钮会从「检测并下载」改为「下载」，点击后重新读取远程清单、给实际下载地址追加时间戳，并优先使用清单里的完整下载地址，失败后继续尝试多个 GitHub 压缩包备用地址。
- 移动端适配：手机视图下顶部操作栏和底部导航固定，内部内容独立滚动，并使用更接近设计稿的全屏糖果风面板。

## 安装教程

1. 打开 Chrome 或 Edge。
2. 在地址栏输入 `chrome://extensions/` 并回车。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择当前目录：`tangxin-zhizhe-extension`。
6. 如果刚修改过 Figma Make 界面源码，先在当前目录执行 `npm install`，再执行 `npm run build` 生成 `dist-ui/`。
7. 初次只使用已构建好的插件时，可以直接加载当前目录；如浏览器提示缺少 `dist-ui/txzz-ui.js`，说明需要先执行上一步构建命令。
8. 打开需要联调的页面。
9. 页面右下角出现「志」字悬浮球，表示插件加载成功。

## 远程账号池配置

推荐使用远程账号池保存账号凭据。账号密码、二维码凭证、token、deviceId、Supabase `service_role` 等敏感信息应放在 Cloudflare Worker 或 GitHub Secrets 中，插件前端只保存 Worker 地址。

配置步骤：

1. 点击「志」字悬浮球打开面板。
2. 进入「账号池」页。
3. 在「远程配置」中填写「云端服务地址」。
4. 选择账号来源模式。
5. 点击「保存配置」。
6. 点击「同步云端」读取云端账号池。
7. 云端账号默认只显示可用账号；需要排查坏账号时，打开「查看已失效云端账号」。

账号来源模式说明：

| 模式 | 说明 |
| --- | --- |
| 云端自动轮换 | Worker 按金币数量从少到多选择可用账号，失败时自动切换下一个账号。 |
| 本地选中账号 | 只使用插件本地保存的账号。 |
| 云端优先，本地兜底 | 优先使用云端账号，失败后尝试本地账号。 |

## 使用教程

### 打开和关闭面板

1. 打开目标页面。
2. 点击「志」字悬浮球。
3. 悬浮球隐藏，控制台展开，默认进入「总览」页。
4. 点击关闭按钮后，面板关闭，悬浮球重新出现。
5. 按住「志」字悬浮球拖动，可调整悬浮球位置。
6. 点击主界面右上角「关于」按钮，可打开项目主页。
7. 桌面端通过左侧导航切换页面，手机端通过底部导航切换页面。
8. 当插件已经获取到当前视频播放链接时，页面右侧会出现视频悬浮按钮，点击后会暂停网页原生视频，并直接打开插件播放器全屏播放。

### 应用页面状态展示

1. 打开插件面板。
2. 点击「应用展示覆盖」。
3. 面板会刷新当前状态区域。
4. 如果页面内有对应状态展示，插件会同步进行页面侧显示更新。

### 查看播放状态

1. 打开任意视频详情页或播放页。

15. 如果主线路播放不稳，在「菜单」的「显示」里点击「备用」一键切到备用线路；播放异常时插件也会自动尝试切换备用线路。

21. 点击「打开线路」或主备线路卡片里的「打开」，也会用补全域名后的完整链接在新窗口打开当前线路，方便直接验证主线路或备用线路是否能播放。
22. 如果当前视频支持下载，可直接点击「下载视频」创建下载任务。
23. 创建下载任务后，播放页会显示当前视频的下载阶段、分片进度、文件大小、更新时间和完整源链接摘要。
24. 当前视频下载卡片可直接复制完整下载源链接；如果任务失败，可直接点击「重试下载」重新创建任务。
25. 下方播放记录会显示旧视频的就绪链接、下载状态和进度，可用搜索框按标题、编号、账号或链接查找，也可切换「全部」「可下载」「可保存」「失败」「有备用」快速定位目标记录。
26. 可切换「最近」「异常」「可保存」「备用」排序，排序会影响播放记录列表和批量报告顺序。
27. 点击播放记录标题旁的「批量报告」可复制当前搜索和筛选结果的批量报告，包含可播放数量、异常数量、备用线路数量、主备完整链接和关联下载任务。

29. 播放记录可直接刷新该视频资源；右侧主按钮会按下载状态自动显示「下载」「查看」「保存」或「重试」，进行中的任务会跳转到下载页查看进度。

### 云端服务体检

1. 打开插件面板。
2. 进入「设置」页。
3. 点击「开始体检」。
4. 插件会优先访问 `/v1/diagnostics`，如果云端服务尚未升级，会自动降级检测 `/v1/status` 和 `/v1/health`。
5. 体检结果会显示总分、整体摘要、分项检查、账号池摘要、服务端建议动作和建议下一步。
6. 如果体检提示账号池为空，可回到「账号池」页上传账号或同步云端。
7. 如果体检提示缺少密钥，需要在 Cloudflare 或本地 `.dev.vars` 中补齐后重新部署。
8. 点击「处理账号池」会自动跳转到账号池页；如果体检发现异常账号，会自动打开失效账号视图。
9. 点击「同步账号」可直接重新同步云端账号池。
10. 点击「复制报告」可把体检结果、账号池摘要、分项检查、建议和服务端建议动作复制到剪贴板，便于保存或排查。
11. 重新打开设置页时会显示当前云端服务地址对应的「上次体检」，可点击「清除上次体检」移除本地历史记录；清除操作不会影响云端账号池和 Worker 服务。

## 常见问题排查

### 页面没有出现悬浮球

1. 确认加载的是 `tangxin-zhizhe-extension` 目录。
2. 确认浏览器扩展页没有报错。
3. 刷新页面。
4. 检查当前页面地址是否匹配 `manifest.json` 的 `matches` 配置。

### 手机端点击按钮无效

1. 刷新页面后重试。
2. 确认没有旧版本插件同时启用。
3. 检查页面是否被其他浮层遮挡。
4. 尝试关闭面板后重新点击悬浮球展开。

### 刷新后仍然看到旧页面

1. 在浏览器扩展管理页点击当前插件的「重新加载」按钮。
2. 确认加载目录中存在 `dist-ui/txzz-ui.js` 和 `dist-ui/txzz-ui.css`。
3. 重新打开或刷新目标页面，不要只刷新扩展管理页。
4. 当前版本已经删除旧 DOM 面板、旧流程浮层和旧更新弹窗；如果仍看到旧面板，通常是浏览器还在运行旧扩展实例，关闭重复安装的旧版本后再刷新页面。

### 构建提示 vite 不是内部或外部命令

1. 在插件目录执行 `npm run deps:check`。
2. 如果提示缺少 `node_modules/.bin/vite.cmd`，说明 `node_modules` 的命令入口损坏。
3. 执行 `npm run deps:repair` 自动修复依赖。
4. 修复完成后重新执行 `npm run build`。

### 构建提示无法解析 hls.js

1. 在插件目录执行 `npm run deps:check`。
2. 如果提示缺少 `node_modules/hls.js/dist/hls.mjs`，说明 hls.js 包安装不完整。
3. 执行 `npm run deps:repair`，脚本会移除损坏的 `hls.js` 目录并重新执行 `npm install`。
4. 修复完成后重新执行 `npm run build`。

### 远程账号池同步失败

1. 检查 Worker 地址是否可访问。
2. 检查 Worker 是否配置了 `SUPABASE_URL` 和 `SUPABASE_SERVICE_ROLE_KEY`。
3. 检查 Supabase 是否已执行 `schema.sql`。
4. 访问 `/v1/health` 查看必填变量是否齐全。
5. 在「设置」页点击「开始体检」，根据分项检查处理密钥、数据库或账号池问题。

### 云端服务体检分数较低

1. 如果提示缺少密钥，补齐 Cloudflare Secrets 或本地 `.dev.vars` 后重新部署。
2. 如果提示数据库连接异常，确认 Supabase 地址、`service_role` 和 `schema.sql` 是否正确。
3. 如果提示账号池为空，先上传本地账号或调用 `/v1/accounts/seed` 写入种子账号。
4. 如果提示异常账号较多，打开账号池页的「查看失效」并重新上传凭据。
5. 如果提示待验证账号较多，逐个点击账号检查，减少播放时临时轮换等待。

### 本地账号上传云端后显示无凭据

1. 确认插件版本为 `1.3.0` 或更高版本。
2. 当前版本已保留云端摘要中的 `hasPassword`、`hasQrcode`、`hasToken` 标记。
3. 如果旧云端账号仍显示无凭据，重新上传该账号或在 Worker 部署新版后重新同步云端账号池。
4. 云端账号如果确实没有任何凭据，会显示「不可用：账号没有可用凭据」。

### 保存账号后页面刷新

1. 确认插件版本为 `1.3.0` 或更高版本。
2. 当前版本已将添加账号弹窗中的按钮全部改为普通按钮，并拦截表单默认提交。
3. 如果仍然刷新，请检查是否同时启用了旧版本插件。
4. 关闭旧版本插件后刷新页面，再重新打开「账号池」页保存。

### 播放详情为空

1. 确认账号池中至少有一个可用账号。
2. 同步远程账号池后再试。
3. 确认云端账号中至少有一个可用账号。
4. 查看 Worker 日志确认服务端接口是否返回错误。

### 下载按钮没有反应

1. 进入「下载」页点击「刷新下载」。
2. 确认视频详情页上的下载按钮已经渲染完成。
3. 检查浏览器是否拦截下载。
4. 如果任务正在下载 M3U8 分片，请等待显示「合并完成，待保存」。

### 保存到设备没有弹窗

1. 检查浏览器默认下载目录是否可写。
2. 查看浏览器下载记录。
3. 如果希望每次选择位置，请在浏览器下载设置中开启「下载前询问保存位置」。
4. 如果插件显示 TS 兜底，说明 MP4 转封装失败但文件仍可保存。

### 检查更新不灵敏或没有检测到新版

1. 进入「设置」页，点击「检查更新」。
2. 新版会强制实时读取远程 `update.json`，不会继续使用旧更新缓存。
3. 设置页会等待本次检测结果返回后再弹窗，不再固定等待 1.4 秒后显示旧结果。
4. 设置页会显示远程版本、远程构建、检测来源、检测模式、清单地址、检测时间、下载地址、候选下载地址、缓存策略、下载策略和更新说明；即使没有新版本，也会显示本次检测结果。
5. 远程 `version` 大于本地 `manifest.json` 的 `version` 时会提醒；版本相同但远程 `build` 晚于本地构建时也会提醒。
6. 自动检测到新版本时会直接弹出更新弹窗，弹窗会显示版本号、构建号、发布时间、检测来源、更新内容和「下载」按钮，不再只提示去设置页。
7. 如果 `update.json` 忘记更新，但远程 README 更新日志已经新增记录，插件会用 README 结果兜底提示。
8. 如果显示检测失败，请确认当前网络可以访问 `https://raw.githubusercontent.com/lsy5920/tangxin-zhizhe-extension/main/update.json`。

### 下载最新版失败

1. 进入「设置」页，未检测过远程信息时点击「检测并下载」；已经检测到远程信息后按钮会显示为「下载」。
2. 插件会先重新检测远程清单，再按清单里的完整下载地址下载 GitHub 主分支最新压缩包。
3. 实际提交下载前会给地址追加时间戳，减少浏览器或代理缓存旧压缩包的概率。
4. 下载会优先使用 `https://codeload.github.com/lsy5920/tangxin-zhizhe-extension/zip/refs/heads/main`，失败后自动尝试 GitHub 备用压缩包地址和 GitHub API zipball 地址。
5. 如果浏览器拦截下载，请打开浏览器下载记录允许保留文件。
6. 如果仍然失败，设置页会显示上次下载错误、所有候选地址和实际尝试地址，请点击「复制信息」保存诊断内容。
7. 如果网络无法访问 GitHub 压缩包地址，请点击设置页「打开地址」或复制设置页展示的下载地址到浏览器中手动打开。

## 安全与隐私

- 不要把账号密码、二维码凭证、token、deviceId 写入插件源码。
- 不要把 Supabase `service_role` 写入插件源码。
- 不要提交 `.env`、`.dev.vars`、日志、截图、浏览器 profile 和运行证据。
- 已经暴露过的密钥应立即轮换。
- 云端账号凭据应由 Worker 加密保存，插件只展示脱敏摘要。
