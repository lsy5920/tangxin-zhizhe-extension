# 嵌入式视频播放系统

本文档记录播放器重构前后的功能矩阵、状态边界和验收标准。播放器界面可以调整，但矩阵中的业务能力不得在重构时丢失。

## 信息架构

- 主控层：进度、播放/暂停、快退、快进、静音、倍速、播放器设置、锁屏和全屏。
- 设置层：按「播放」「画面」「音频」「工具」四类组织低频能力，不在画面上平铺同权重按钮。
- 状态层：等待链接、默认暂停、缓冲、播放、错误恢复、锁屏、断点续播和全屏体检。
- 手势层：单击显隐、三区双击、长按、横向定位、左右竖滑和桌面滚轮。
- 内核层：ArtPlayer 负责媒体生命周期，hls.js 负责 HLS、清晰度和弱网恢复。
- 全屏层：浏览器全屏优先，页面内沉浸兜底；负责方向、安全区、画面重绘、常亮和退出清理。

## 功能矩阵

| 领域 | 功能 | 入口 | 状态与失败处理 |
| --- | --- | --- | --- |
| 播放 | 播放/暂停 | 主控、中央按钮、空格/K、中区双击、系统媒体键 | 无链接禁用；进入详情默认暂停；失败显示可恢复错误 |
| 进度 | 点击/拖动定位 | 可聚焦进度条 | 拖动显示时间预览；键盘左右键按步长跳转 |
| 跳转 | 快退/快进 | 主控、左右方向键、左右双击、媒体键 | 步长支持 5/10/30/60 秒；边界自动限制 |
| 线路 | 推荐/主线/备用/历史记录 | 播放设置 | 无链接线路禁用；起播后锁定当前源；连续错误自动切备用；历史预览始终使用该记录自己的编号和主备线路 |
| 清晰度 | 自动与 HLS 档位 | 播放设置 | 非 HLS 或无多档清晰度时显示自动并禁用切换 |
| 倍速 | 0.75/1/1.25/1.5/2 倍 | 主控快捷切换、播放设置 | 长按右侧临时 3 倍，松开恢复原倍速 |
| 音频 | 音量、静音 | 主控、音频设置、上下方向键、M、右侧竖滑、滚轮 | 0 自动静音；偏好本地保存；反馈显示在右侧 HUD |
| 画面 | 比例、填充、方向 | 画面设置 | 比例自动/横屏/竖屏；填充原比例/裁满/铺满；方向自动/横屏/竖屏 |
| 亮度 | 60%～140% | 画面设置、左侧竖滑、Shift+滚轮 | 使用独立遮罩，不向 video 添加 filter，避免 Android 黑屏 |
| 工具 | 截图、画中画、重载 | 工具设置 | 浏览器拒绝时给出非阻断提示，不把工具失败误报成播放中断 |
| 链接 | 复制、打开、下载 | 工具设置、播放器卡片 | 始终使用补全域名的完整链接；无视频编号时禁用下载 |
| 诊断 | 播放器诊断、全屏体检、重新居中 | 工具设置 | 报告只在面板弹层查看；不覆盖剪贴板 |
| 手势 | 单击、双击、长按、横滑、竖滑、右键菜单 | 视频画面 | 控件操作与画面手势隔离；锁屏后所有画面手势停止，只保留解锁；无链接时不拦截页面滚动 |
| 全屏 | 进入、退出、锁屏 | 主控、F、Esc、顶部返回 | 宿主/播放器/页面根节点逐级尝试；失败进入沉浸兜底；快速进退使用代次隔离并取消旧重绘任务 |
| 移动端 | 横屏、紧凑控制、安全区 | 全屏自动处理 | 紧凑横屏仍保留锁屏入口；系统方向锁失败时使用 CSS 横屏兜底；画面位置按左右安全区实际校准 |
| 系统能力 | Media Session、Wake Lock | 自动 | 不支持或拒绝时静默降级，不影响核心播放 |
| 可访问性 | 标签、焦点、键盘、减少动态效果 | 全部控制 | 设置菜单进入后聚焦当前分类、Tab 循环、方向键切页、关闭后恢复焦点；隐藏控制不进入 Tab；进度条可聚焦；锁屏/错误使用状态语义 |

## 全屏状态顺序

1. 用户点击全屏后才设置全屏意图，普通播放不得误触发沉浸模式。
2. 准备插件宿主和 video 自适应样式，再按插件宿主、播放器壳、页面根节点顺序请求浏览器全屏。
3. 浏览器全屏成功后请求方向锁定；失败时保留页面内沉浸模式和 CSS 横屏兜底。
4. 全屏期间校正 video 合成层、隐藏 ArtPlayer 遮罩、应用安全区并运行覆盖率诊断；每次进入生成独立代次，旧代次定时器不得修改新状态。
5. Esc 优先关闭设置菜单，其次解除锁屏，最后退出全屏。
6. 退出时先取消全部待执行的重绘/诊断任务，再清理系统全屏、沉浸状态、方向锁、强制内联样式和宿主类，必须回到原播放器卡片。

## 真实验收

- 使用 Playwright 随附 Chromium 的持久化上下文加载解压扩展。
- 通过浏览器级 CDP 检查最终启动参数和扩展服务线程目标。
- 在真实网站验证主备播放链接、默认暂停、播放/定位/倍速/音量、四类设置菜单、错误恢复和报告弹层。
- 检查普通播放器、桌面全屏、横屏矮屏和 320/390/640/1024/1536 像素布局。
- 验证 Esc 顺序、菜单焦点循环与恢复、紧凑横屏锁屏解锁、右键菜单、历史记录主备切换和当前记录下载。
- 增加方向锁拒绝、进入后 100/300 毫秒快速退出、退出后立即重进、弱网零散错误不累计切线等回归场景。
- 验证退出全屏回面板、`data-txzz-fs-forced` 无残留、控制台异常和失败网络请求。

## 触摸长按与右键边界

- 触摸或手写笔长按专用于左侧连续快退、右侧临时倍速，不打开浏览器或播放器链接菜单。
- 桌面鼠标右键继续打开播放器菜单，保留复制链接、新窗口打开和诊断入口。
- Android Chromium/Edge 可能把触摸长按合成为 `contextmenu`；手势层必须结合 PointerEvent 与 `sourceCapabilities.firesTouchEvents` 判断来源，不能依赖屏幕宽度或 User-Agent。
- 真实验收需覆盖触摸长按、pointercancel 后恢复、鼠标右键、全屏进退和混合输入设备。
